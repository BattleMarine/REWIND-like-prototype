## 작업 인계 방식

- 배정할 때 오케스트레이션은 위 표에 담당 작업을 표시하고 해당 세션에 기준 커밋, 목적, 변경 범위, 완료 기준을 전달한다. 한쪽이 바쁘면 다른 쪽에 독립 작업을 배정한다. 같은 파일이나 인터페이스를 동시에 수정할 때 생길 충돌은 배정 전에 조율한다.
- 진행 중 교대할 때는 기존 담당자의 편집을 마무리하고 브랜치나 작업 폴더, 미커밋 변경 파일, 이미 확인한 결과, 미해결 문제, 바로 다음 행동을 기록한다. 새 담당자는 실제 작업 트리와 대조한 뒤 이어간다.
- 검토 후에는 채택한 결정과 이유, 재사용할 구현 위치, 검증 범위와 남은 문제를 근거 문서·커밋과 연결한다. 다른 세션이 이미 작업 중이고 그 결정이 영향을 주면 즉시 전달한다. 대기 중인 세션에는 다음 배정 때 최신 인계를 전달한다.
