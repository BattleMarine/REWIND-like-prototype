## 1. 현재 결론

128 학습은 세 슬롯 모두 완료했다. 세 시나리오 몸·손 종합 오차가 가장 낮은 A(219.72mm)를 튜닝 베이스로 사용한다.

**학습·평가·모델 저장 경로는 동작하며 몸 형태 복원도 개선됐다. 그러나 손 축소와 자세 오류가 남아 있어 정확한 REWIND-like 시연 모델이 완성된 상태는 아니다.**

1. 초기 1,000페어 학습에서는 2D가 중앙에 몰리고 3D가 축소됐다. 같은 규모에서 epoch를 늘린 v1.1도 이를 충분히 해결하지 못했다.
2. v1.4는 한 클립에 GT 2D·hand용 GT 상체를 제공하고 충분히 반복 학습하면 몸과 손 형태를 복원할 수 있음을 보였다. 이는 실제 RGB 추론이나 일반화 성공과 다르다.
3. v1.2는 ArchVis 전체 학습으로 2D·몸 복원이 개선됐지만, CityPark·Downtown에서는 큰 위치 오류와 축소를 보였다.
4. 대조·원점 개입 시험에서 카메라의 절대 world 원점 의존성을 확인했다. v1.5의 통제 학습에서는 첫 프레임 stereo 중점 표현이 이 민감도와 도시 표본 오류를 줄였다.
5. 중점 모델도 손 뼈 길이가 GT의 약34.6%에 머문다. v1.5.1에서 GT 상체로 local 오차는10.8% 줄었지만 뼈 길이는GT의약33.7%로 축소가 남았다. 상체 오류만으로 손 실패를 설명할 수 없다.

6. v1.5.3에서는 예측2D 특징·GT 상체로 한 클립을 충분히 반복해 body10.78mm·hand5.65mm와 형태 복원을 확인했다. 단일클립 학습 가능성의 근거이며 다중클립 일반화는 미확인이다.

위 결론은 정해진 표본·조건의 근거다. 논문 성능 재현, 다양한 인물·동작의 독립 일반화, 완결된 RGB-only 추론, 실시간 영상 시연을 입증한 것은 아니다.

## 10. 계속 갱신하는 방식

- 새 테스트를 설계하거나 결과를 검토할 때 이 문서의 상단 날짜·상태·트리·표·결론·다음 작업·보존 경로를 함께 갱신한다. 아직 회수되지 않은 결과는 대기로 둔다.
- 전용 결과 보고서에는 원본 수치·설정·revision·SHA·검증 근거를 보존한다. 이 문서는 종합 판단의 진입점, `V1_EXPERIMENT_LINEAGE.md`는 날짜별 분기·판정 이력으로 유지한다.
- 관찰과 원인 가설, 로컬 검증과 실제 GPU 결과, GT 진단과 배포 입력 결과를 구분한다. 다른 평가 조건의 숫자를 같은 성능 순위로 합치지 않는다.
- 판단이 바뀌면 새 근거와 변경 이유를 아래 이력에 남긴다. 과거 개별 보고서의 당시 판단을 근거 없이 덮어쓰지 않는다.
- 결과 검토 시 갱신하는 운영 규칙이며 별도 백그라운드 감시나 새 실행 승인을 의미하지 않는다.
