# v2 — 세 시나리오 전체 train 통합 학습

2026-11-18 사용자 명명·진행 승인. 후속 사용자 승인으로 입력 준비·학습 각1회8시간을 확정하고 전용 인프라 구현·신규14검사와 root 검토를 완료하고 고정본 발급 대기 중이다. 실제 v2 학습은 미시작이다.

## 범위와 계보

ArchVisInterior_ArchVis_RT·CityPark_Showcase·DowntownWest_Demo_Environment의 RGB·pose 추출본 전체 train으로 frontend/body/hand 통합 모델을 준비한다. 공식 validation은 시나리오별로 평가하고 test는 설정 선택에 사용하지 않는다. 기존 v1.3 혼합학습 제안은 v2로 확대·이관하며 별도 v1.3 실행은 하지 않는다. v1.2 전체 학습 경로와 v1.5 중점 카메라 표현, v1.5.2/1.5.3 진단 결과를 설계 근거로 사용한다. 번호 상승은 논문 성능 재현·완성 선언이 아니다.

기존 실험 manifest·checkpoint는 보존한다. 초기화(새 학습/기존 모델 활용), 학습량, GT/예측 상체 학습 정책과 평가 조건은 구현 전 명시한다. 예측 상체를 사용하는 실제 추론 경로와 시나리오별 평가를 포함할 계획이다. 단일클립 성공을 전체 데이터 수렴으로 외삽하지 않는다.

## 시간 상한 — 후속 사용자 확정

캐싱·입력 준비와 GPU 학습의 1회 전체 상한을 각각28,800초(8시간)로 확정한다. 중간 동기화도 포함하며, 내부에 종료1,320초(package600·copy/readback600·checkpoint120)를 예약해 계산/중간보존 구간은최대27,480초(7시간38분)다. 외부worker timeout28,920초 이후SIGINT60초/kill-wait30초로 제한한다. 같은VM의연속16시간이나18시간을승인·보장하지 않는다. 사용한VM시간도고려한다. 전체누적시간·전송·디스크예산은별도결정이며자동재호출하지않는다.

v1.2 A100 본학습 호출 합계는 약3시간5분이며 준비·복원·최종 보관 전체 시간 또는 순수 GPU 시간은 아니다. 감사에는6시간 상한 중 KeyboardInterrupt로 종료된 사례도 있었다. 상한 확대만으로 연결·VM 종료를 해결하지 못한다. [학습 실측](V12_TRAINING_RESULTS.md) · [감사·재개 근거](V12_AUDIT_RESUME.md).

Colab은 가용성과 사용량에 따라 수명이 달라진다. 공식 FAQ는 무료 최대12시간, 충분한 compute units가 있는 Pro+ 연속 실행 최대24시간을 안내하나 일정 실행시간을 보장하지 않는다. [공식 FAQ](https://research.google.com/colaboratory/faq.html).

전체 누적 비용은 정리 후 split별 사용 가능 프레임·연속클립 수, GPU·IO 실측, 학습량을 바탕으로 별도 산출한다. 정리 전 train_val 파일 수를 실제 train 수로 취급하지 않는다. 시간 상한 외 전송·RAM·디스크 상한은 독립적으로 산정한다.

## 준비 작업

1. 세 시나리오 공식 split과 추출본을 대조해 사용 가능한 train/validation 목록·클립·크기를 산출한다.
2. 기존 v1.2의 감사·캐시·학습 재개 경로를 검토하고, v2 입력 identity와 중점 카메라 표현을 연결한다.
3. 완료 캐시 구간과 checkpoint를 주기적으로 Drive에 보존할 방식을 준비한다. 전체 캐시 반복 복사 대신 완료 shard 단위 보관·검증을 검토하며 원본/캐시 업로드는 기존 사용자 담당 규칙을 따른다. 마지막 셀만의 보관에 의존하지 않는다.
4. 실제 GPU 종류를 제한하지 않고 실행 전 비용·남은 디스크·중단/재개 조건을 고정한다. 새 VM 복원 지원은 기존 지원 범위를 점검한 후 검증한다.
5. 구현·root 검토·고정 revision/노트북 준비 후 테스트 세션에 인계한다. 이번 명명과 시간 권고로 원격 대규모 작업을 자동 시작하지 않는다.
