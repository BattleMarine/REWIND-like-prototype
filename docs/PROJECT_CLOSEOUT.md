# 최종 발표 종료 기록

2026-11-23 최종 발표를 마쳤다. 이후 연구 주제와 기존 데이터의 재사용 여부는 열어 둔다.

## 베이스 모델을 다시 읽을 때

출발점은 v2 128×128 A(seed 42)다. 2D frontend와 3D body는 각각 epoch 3, hand는 epoch 2 가중치를 사용했다. 세 시나리오의 validation 421클립·16,425프레임에서 베이스의 종합 오차는 219.72 mm였다. 발표에서 선정한 설정은 이 가중치를 그대로 두고 Body와 Hand의 DDIM 추론을 각각 10단계에서 2단계로 줄인 것으로, 같은 평가에서 202.20 mm를 기록했다. [평가 방법](V23_DDIM.md) · [실험 종합 보고서](EXPERIMENT_RESULTS_REPORT.md)

처음에는 전체 데이터를 준비할 필요가 없다. 다음 순서로 한 클립과 한 함수를 연결해 볼 수 있다.

1. 로컬 `outputs/v2_plan_inputs/gpu128_A_final/`에서 같은 이름의 GIF와 NPZ 한 쌍을 고른다. 세 시나리오별로 50프레임의 정답과 베이스 예측이 보존돼 있다.
2. [추론 코드](../scripts/v23_eval.py)의 `prepare`에서 클립 입력을, `cascade_prediction`에서 Body 예측이 Hand 입력으로 이어지는 부분을, `score_arrays`에서 예측과 정답을 비교하는 부분을 읽는다.
3. 가중치를 직접 불러오거나 소스를 바꿔 볼 때는 [A 모델 재현·튜닝 가이드](V2_GPU128_A_PORTABLE_BUNDLE.md)를 사용한다. 완성된 로컬 묶음은 `outputs/v2_plan_inputs/gpu128_A_portable_release/v2_128_A_final_model_and_cache.zip`이다. 모델·캐시가 포함된 55,068,837,571바이트 파일이며 Git 추적에서 제외돼 있다. 새 컴퓨터에서 다시 열 계획이라면 별도로 보관할 파일이다.

## 보존 범위

128·256 캐시는 각각 1,063샤드·136,011페어까지 생성했다. 128 A·B·C는 학습과 평가를 마쳤고, 256 A·B는 학습 도중 중단했다. 재개 후보와 당시 판단은 [종합 보고서](EXPERIMENT_RESULTS_REPORT.md)에서 확인할 수 있다. 발표에 사용한 결과와 이후의 개별 실험은 각 평가 조건을 함께 읽는다.

이번 정리는 문서와 보존 위치에 한정했다. 원본 데이터, 캐시, 체크포인트의 폐기 여부는 다음 작업에서 필요한 자료를 정한 뒤 결정한다.
